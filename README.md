**Microplastic Detection Using YOLOv8**

A computer vision project for the automated identification of microplastic particles in water samples. The detection model is based on YOLOv8 and was developed using an augmented image dataset prepared through Roboflow.

**Dataset:**

The dataset contains **1,154 augmented images**. Image augmentation was applied to increase data diversity and improve the model's ability to recognize microplastic particles under varying visual conditions.

**Model:**

**YOLOv8** was employed as the object detection architecture to locate microplastic particles within input images using bounding-box predictions.

**Application:**

The developed system can be applied to:
* Microplastic pollution monitoring
* Water quality assessment
* Environmental research
* Automated image-based analysis

**Development Tools:**

Python · YOLOv8 · Roboflow · Computer Vision · Deep Learning
